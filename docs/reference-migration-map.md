# Reference migration map

Source: `akshay-engineering-portfolio-final-responsive-fixed.html`

Status values in the original audit table record the pre-migration state, as
required before implementation. The completed migration uses `src/app/page.tsx`
as a server-rendered reference-homepage boundary: it reads the immutable source
at build time, removes executable scripts, replaces only the embedded portrait
data URL with its byte-identical public asset, and emits the reference DOM
unchanged. `src/app/reference.css` is extracted verbatim.
`public/reference-runtime.js` contains the reference runtime, with only a
late-loading boot-ready guard added for Next.js script timing.

Post-migration status: every selector/system below is **migrated and visually
verified** at all nine required viewports. The previous application stylesheet
is isolated to `src/app/projects/layout.tsx` and cannot compete on the homepage.
