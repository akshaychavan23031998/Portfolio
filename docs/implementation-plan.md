1. Audit the reference HTML and local assets for content, visual tokens, links, and responsive behavior.
2. Scaffold a strict Next.js App Router application with Tailwind CSS, linting, formatting, testing, and the requested interaction libraries.
3. Organize and optimize local profile, project, testimonial, résumé, favicon, and Open Graph assets.
4. Build typed configuration and content data, then implement the homepage, project case studies, metadata routes, error states, theme, command palette, navigation, filters, carousel, and validated contact form.
5. Add responsive, accessible, reduced-motion-aware styling and restrained Motion/GSAP/Lenis enhancements.
6. Add component and end-to-end coverage for navigation, filters, forms, theme, command palette, media, routes, and mobile layout.
7. Run formatting, linting, type checks, unit tests, production build, Playwright tests, and browser-based visual/accessibility checks across representative desktop, tablet, and mobile viewports; fix all discovered issues.
8. Document architecture, content editing, email integration, testing, accessibility, performance, deployment, and project maintenance.
